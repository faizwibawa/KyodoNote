# KyodoNote 📚

**KyodoNote** is a collaborative learning platform for university students to create, share, discover, and curate **course-specific study notes and flashcards**.

The platform helps students find relevant and trustworthy study materials through community-driven mechanisms such as **upvotes, downvotes, peer validation, comments, and contributor reputation scores**.

> **Kyodo (共同)** represents the idea of *joint or collaborative work*, reflecting the core concept of KyodoNote: learning together through shared knowledge.

## Project Overview

Finding well-structured and course-specific study materials can be difficult, especially when preparing for exams. KyodoNote aims to provide a centralized repository where students can contribute and discover supplementary learning materials organized by **course, category, and topic**.

The platform is designed as a **student-driven public learning repository** and is not intended to replace official learning resources, conduct examinations, or provide official academic grades.

## Main Features

### Student Features

* Register, log in, and manage accounts
* Search and filter study materials by course or topic
* Create and publish study notes and flashcards
* Edit and delete personal contributions
* View and save useful materials
* Upvote and downvote content
* Provide peer validation and relevance ratings
* Comment and reply to other users
* Report inappropriate or problematic content
* View and improve contributor reputation

### Content Moderation

* Review reported content
* Hide or take down inappropriate materials
* Monitor content quality and relevance
* Review user contribution activity
* Handle content-related violations

### Administration

* Manage user accounts and roles
* Manage courses, categories, and topics
* Manage learning materials and reports
* Configure reputation scoring rules
* Monitor platform activity and usage statistics

## User Roles

| Role                  | Description                                                                |
| --------------------- | -------------------------------------------------------------------------- |
| **Student**           | Creates, discovers, uses, and evaluates study materials                    |
| **Content Moderator** | Reviews reports and maintains content quality                              |
| **Administrator**     | Manages users, content, courses, reputation rules, and platform statistics |

## Project Scope

KyodoNote covers:

* Course-specific study notes
* Flashcards
* Material discovery and filtering
* Community-based content validation
* Voting and relevance evaluation
* Comments and discussions
* Contributor reputation
* Content moderation
* User and course management
* Platform activity statistics

KyodoNote does **not** cover:

* Conducting official examinations
* Providing official academic grades
* Replacing lecturers' or universities' official learning resources
* Acting as an official academic assessment system
